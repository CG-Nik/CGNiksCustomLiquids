# CGNiksCustomLiquids
This mod add news Liquids.  
This mod needs to be on both the Client and the Server.  
I highly recommend having https://github.com/CG-Nik/CrippleDamageProtectionPatch if you use this mod, as any Damage Protection effects break without it.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
